AI 골드 러쉬 파트너스 웹사이트의 각 페이지별 상세 설계를 다음과 같이 정의하겠습니다.

## 1. 홈페이지 (Landing Page)

### 구조 및 레이아웃
- 풀스크린 히어로 섹션
- 스크롤 기반의 단일 페이지 구조
- 반응형 그리드 시스템 (12컬럼)

### 주요 섹션
1. 히어로 섹션
   - 배경: 동적 데이터 시각화 애니메이션
   - 메인 헤드라인: "한국 AI 기술, 세계를 선도하다"
   - 서브 헤드라인: "한국인공지능협회와 피앤에프글로벌이 함께하는 AI 골드 러쉬 파트너스"
   - CTA 버튼: "AI 챔피언 로드 알아보기", "투자 신청하기"

2. 핵심 가치 제안
   - 4컬럼 그리드 레이아웃
   - 각 가치별 아이콘, 제목, 간략한 설명
   - 호버 효과: 아이콘 색상 변화, 설명 텍스트 확장

3. 금융 지원 유형
   - 캐러셀 또는 탭 인터페이스
   - 각 유형별 아이콘, 제목, 핵심 특징
   - CTA: "금융 지원 옵션 자세히 보기"

4. AI 챔피언 로드 하이라이트
   - 2컬럼 레이아웃: 이미지 + 텍스트
   - 애니메이션 인포그래픽: 투자 규모 시각화
   - CTA: "프로그램 자세히 보기"

5. 협회 경로 강조
   - 인터랙티브 프로세스 다이어그램
   - 호버 시 각 단계 상세 설명 팝업
   - CTA: "협회 가입 방법 알아보기"

6. 성과 수치
   - 카운터 애니메이션
   - 4개의 주요 지표 그리드 레이아웃

7. 비전 메시지 (패럴랙스 섹션)
   - 전체 너비 배경 이미지
   - 오버레이 텍스트: "한국의 AI 기술로 세계를 바꾸는 여정에 함께합니다"

8. 파트너 로고 슬라이더
   - 자동 스크롤 캐러셀
   - 로고 호버 시 컬러 변환 효과

### 인터랙션 및 애니메이션
- 스크롤 기반 요소 페이드인
- 부드러운 섹션 간 전환
- 데이터 시각화 요소의 로딩 애니메이션
- CTA 버튼 호버 효과

### 반응형 고려사항
- 모바일: 단일 컬럼 레이아웃, 햄버거 메뉴
- 태블릿: 2컬럼 그리드로 전환
- 데스크톱: 최대 4컬럼 그리드 활용

2. AI 챔피언 로드 소개

   - 아이콘 그리드: 대상 분야 시각화
   - 탭 인터페이스: 차별화 포인트 설명

3. 경영진 및 핵심 팀 소개
   - 필터링 가능한 인물 카드 그리드
   - 호버 시 약력 팝업

### 인터랙션 및 애니메이션
- 인물 카드 플립 효과 (호버 시 상세 정보)
- 타임라인 스크롤 애니메이션
- 섹션 전환 시 부드러운 페이드 효과

### 반응형 고려사항
- 모바일: 단일 컬럼, 아코디언 메뉴로 정보 구성
- 태블릿: 2컬럼 그리드, 탭 인터페이스 유지
- 데스크톱: 풀 레이아웃, 사이드바 네비게이션 추가

## 3. 투자 구조 (Investment Structure)

### 구조 및 레이아웃
- 상단 내비게이션: 앵커 링크로 각 섹션 이동
- 메인 컨텐츠: 탭 인터페이스 또는 아코디언 메뉴

### 주요 섹션
1. 다양한 자금 지원 형태
   - 인터랙티브 비교 테이블
   - 각 유형별 상세 설명 (호버 시 확장)
   - 인포그래픽: 지원 형태별 특징 시각화

2. 자금 지원 선택 가이드
   - 인터랙티브 의사결정 트리
   - 결과 기반 추천 시스템
   - 사례 기반 카드 UI

3. 단계별 투자 프로세스
   - 애니메이션 플로우차트
   - 각 단계 호버 시 상세 설명 팝업
   - 프로그레스 바: 전체 과정 중 현재 위치 표시

4. 단계별 투자 금액 및 조건
   - 탭 인터페이스: 시드, 성장, 확장 단계
   - 인터랙티브 슬라이더: 투자 범위 시각화
   - 체크리스트: 필요 서류 및 조건

5. 투자 후 지원 프로그램
   - 아이콘 그리드: 각 지원 프로그램 종류
   - 케이스 스터디 슬라이더: 실제 지원 사례
   - CTA: "멘토링 신청하기"

### 인터랙션 및 애니메이션
- 스크롤 기반 단계별 애니메이션
- 데이터 시각화 요소의 로딩 애니메이션
- 호버 시 추가 정보 표시 (툴팁 또는 확장 패널)

### 반응형 고려사항
- 모바일: 아코디언 메뉴로 정보 구조화
- 태블릿: 2컬럼 그리드, 스크롤 테이블
- 데스크톱: 사이드바 네비게이션, 풀 테이블 뷰

## 7. 신청하기 (Apply Now) - 계속

### 주요 섹션
1. 회원사 확인 단계
   - 간결한 폼 디자인: 기업명, 사업자등록번호, 협회 회원번호
   - 실시간 확인 피드백: 입력 즉시 회원사 여부 확인
   - 비회원사 안내 섹션: 회원가입 유도 메시지와 CTA

2. 신청 폼 종류 선택
   - 지원 유형 카드 UI: 투자, 대출, M&A, 상장, 복합 지원
   - 각 카드: 아이콘, 간략 설명, 적합 기업 특성
   - 선택에 따른 맞춤형 안내 텍스트

3. 투자 신청 폼
   - 단계별 폼 레이아웃: 진행 상태 인디케이터
   - 섹션 구분: 기업 정보, 담당자 정보, 기술 분야, 자금 요청 정보, 기업 소개, 재무 정보
   - 파일 업로드 영역: 드래그 앤 드롭 지원
   - 폼 유효성 검사: 실시간 피드백 및 오류 표시

4. 대출/M&A/상장 지원 신청 추가 정보
   - 조건부 폼 필드: 선택한 유형에 따라 다른 입력 필드 표시
   - 툴팁: 각 항목별 가이드 및 예시
   - 단계별 진행 저장: 나중에 이어서 작성 가능

5. 지원 후 안내
   - 성공 페이지: 애니메이션과 확인 메시지
   - 다음 단계 타임라인: 예상 진행 일정 시각화
   - 자동 이메일 발송: 접수 확인 및 준비 사항 안내

### 인터랙션 및 애니메이션
- 단계별 전환 애니메이션: 부드러운 슬라이드 효과
- 진행 단계 시각화: 완료된 단계 하이라이트
- 조건부 폼 전환: 선택에 따른 폼 필드 표시/숨김
- 파일 업로드 진행 상태 표시: 프로그레스 바

### 반응형 고려사항
- 모바일: 수직 스택 레이아웃, 간소화된 폼 구성
- 태블릿: 2단 레이아웃, 사이드바 도움말
- 데스크톱: 멀티컬럼 레이아웃, 인라인 도움말 및 설명

## 8. 협회 회원사 전용 (Member Area)

### 구조 및 레이아웃
- 보안 로그인 페이지
- 사이드바 네비게이션 + 메인 컨텐츠 영역

### 주요 섹션
1. 회원사 로그인
   - 미니멀한 로그인 폼: ID, 비밀번호
   - 2단계 인증 옵션 (선택적)
   - 로그인 상태 유지 옵션
   - 아이디/비밀번호 찾기 링크

2. 회원사 대시보드
   - 환영 메시지 및 중요 공지사항
   - 신청 현황 요약: 그래프 또는 카드 UI
   - 최근 업데이트 및 할 일 목록
   - 퀵 액세스 링크: 자주 사용하는 기능

3. 회원사 전용 자료
   - 자료 카테고리 탭: 투자 가이드, 템플릿, 교육 자료
   - 문서 카드 그리드: 썸네일, 제목, 간략 설명

## 반응형 구현 상세 계획

### 모바일 최적화 (768px 이하)
- 네비게이션: 햄버거 메뉴로 전환, 터치 최적화된 드롭다운
- 그리드 레이아웃: 단일 컬럼 스택 구조
- 폰트 크기: 가독성 유지를 위한 적절한 크기 조정 (최소 14px)
- 터치 대응: 버튼 크기 최소 44px x 44px 유지
- 히어로 섹션: 텍스트 중심 디자인, 배경 이미지 최적화
- 플로팅 CTA: 화면 하단에 고정된 주요 CTA 버튼
- 이미지 최적화: 저해상도 버전 자동 제공

### 태블릿 최적화 (768px~1023px)
- 네비게이션: 축소된 메뉴 항목, 중요 항목만 표시
- 그리드 레이아웃: 2컬럼 구조 활용
- 사이드바: 접을 수 있는 옵션 제공
- 컴포넌트 배치: 가로 스크롤 카드 대신 그리드 형태로 전환
- 차트 및 시각화: 반응형 크기 조정, 상호작용 유지

### 데스크톱 최적화 (1024px 이상)
- 네비게이션: 전체 메뉴 표시, 드롭다운 서브메뉴
- 그리드 레이아웃: 3~4컬럼 활용한 풍부한 정보 배치
- 사이드바: 고정형 또는 스크롤 따라다니는 형태
- 고급 인터랙션: 호버 효과, 패럴랙스 스크롤 등 활용
- 대시보드: 멀티컬럼 레이아웃의 종합 정보 제공
